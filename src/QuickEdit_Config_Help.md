# QuickEdit 使用说明

## 快捷键

- `Ctrl+F`：查找当前文档（查找栏显示匹配数，支持大小写匹配）。
- `Ctrl+H`：替换当前文档（支持替换当前匹配或全部替换）。
- `Ctrl+S`：保存当前可编辑文档。
- `F2`：重命名当前文件或文件夹。
- `Ctrl+``：启动外部终端（新的 cmd 窗口）。当前文件属于工作区时进入工作区根目录，单文件进入其所在目录，无文件时进入用户目录。

## 文件能力

- 文本与 Markdown：可编辑、保存和批注。
- Markdown：编辑/预览使用当前内存内容，预览不会修改原文；预览状态下选中文本也可以添加批注。
- XLSX：支持 Sheet 切换、基础单元格编辑和保存。
- PDF / DOCX：只读阅读，可添加批注。

## 查找与替换

查找与替换只在当前文档内生效，不会修改原文件内容，也不会把文档标记为未保存。PDF、DOCX、XLSX 暂不支持完整替换。

## 批注

批注保存在原文件同目录的伴生 `.qnote` 文件中，不写入原文件。批注可以关联全文、文本选区、PDF 页、Excel 单元格和 Markdown 预览选区。

## 状态与路径

- 状态栏显示当前位置：文本显示当前行，Excel 显示 Sheet 与单元格，PDF 显示当前页。
- 点击文件元信息或右键"复制文件路径"可把完整文件路径复制到剪贴板。

## 工作区

- 打开文件夹只读取元数据，选中文件后才加载正文。
- 从列表移除不会删除磁盘文件。
- 搜索框过滤当前已加载的文件和文件夹。

## 外观与设置

- 浅色主题为默认，选择后会记住并在重启后保持。
- 深色主题暂时不支持，选择时会有提示；完整深色外观已排入后续版本。

## Windows 集成

安装包支持命令行打开、单实例转发，以及资源管理器右键/Open With 注册。

本帮助为只读说明，不会修改任何文件。
