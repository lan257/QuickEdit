# QuickEdit 使用说明

## 快捷键

- `Ctrl+F`：查找当前文档（匹配处会高亮，查找栏显示匹配数，支持大小写匹配）。
- `Ctrl+H`：替换当前文档（支持替换当前匹配或全部替换）。
- `Ctrl+S`：保存当前可编辑文档。
- `F2`：重命名当前文件或文件夹（输入框预填当前名称并选中主名）。
- `F5`：重新加载当前文档；未打开文档时重新加载当前工作区，有未保存修改时先确认。
- `Alt+↑` / `Alt+↓`：切换到上一个 / 下一个可见文档，到头后从头开始。
- Ctrl+反引号键：打开/关闭内置终端面板。当前文件属于工作区时进入工作区根目录；“文档”分区中的文件和无当前文件时进入文档/quickedit目录。

## 界面

- 左侧文件栏右边缘可拖动调整宽度，宽度会被记住；双击该边缘恢复默认宽度。
- 图片预览：滚轮以指针位置为锚点缩放，按住左键拖动平移，双击在“适应窗口”和“100%”之间切换。
- 页面背景：设置里可选 4 款内置渐变或自选本地图片；「背景可见度」越大，侧栏、批注面板和窗口边缘越透出背景，正文卡片不受影响。
- 正文卡片：正文区是浮在背景之上的实心纸面，带描边、圆角和投影，可在设置的「页面背景与质感」中关闭。

## 文件能力

- 文本与 Markdown：可编辑、保存和批注。
- Markdown：编辑/预览使用当前内存内容，预览不会修改原文；预览状态下选中文本也可以添加批注。
- 新建的文档打开后默认处于编辑模式，可手动切换到预览（Markdown）。
- XLSX：支持 Sheet 切换、基础单元格编辑和保存。
- PDF / DOCX：只读阅读，可添加批注。

## 查找与替换

查找与替换只在当前文档内生效，不会修改原文件内容，也不会把文档标记为未保存。PDF、DOCX、XLSX 暂不支持完整替换。

## 批注

批注保存在原文件同目录的伴生 `.qnote` 文件中，不写入原文件。批注可以关联全文、文本选区、PDF 页、Excel 单元格和 Markdown 预览选区。

编辑模式下选择"当前选区"后，选区会被记住：移动光标或点击文档其他位置不会丢失选区；重新选中文本会使用新的选区；编辑了文本内容后，记住的选区会失效并需要重新选择。

## 状态与路径

- 状态栏显示当前位置：文本显示当前行，Excel 显示 Sheet 与单元格，PDF 显示当前页。
- 点击文件元信息或右键"复制文件路径"可把完整文件路径复制到剪贴板。
- 右键菜单在鼠标当前位置弹出。

## 工作区

- 打开文件夹只读取元数据，选中文件后才加载正文。
- 从列表移除不会删除磁盘文件。
- 搜索框过滤当前已加载的文件和文件夹。

## 外观与设置

- 浅色主题为默认，选择后会记住并在重启后保持。
- 深色主题暂时不支持，选择时会有提示；完整深色外观已排入后续版本。
- 设置中的开关项（关闭前确认、本地批注、恢复上次工作区、Windows 集成）切换后点击"保存设置"生效。

## Windows 集成

安装包支持命令行打开、单实例转发，以及资源管理器右键/Open With 注册。

本帮助为只读说明，不会修改任何文件。
